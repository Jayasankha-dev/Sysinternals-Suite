Analyst Playbooks & Reference Workflows

This chapter turns the handbook into repeatable operational playbooks.

18.1 Suspicious Windows Process

  1. Capture process identity and path.
  2. Inspect parent-child relationship.
  3. Check signature and hash.
  4. Review file and registry activity.
  5. Review network connections.
  6. Correlate with Sysmon and Windows logs.
  7. Assess scope and contain if required.

18.2 Suspicious Android Application

  1. Record package and signing information.
  2. Review permissions and components.
  3. Check device telemetry.
  4. Use an authorized lab for dynamic analysis.
  5. Preserve evidence and escalate if compromise is suspected.

18.3 Suspected Firmware Compromise

  1. Escalate to specialist responders.
  2. Record platform and firmware state.
  3. Validate Secure Boot and trusted measurements.
  4. Use vendor-supported recovery procedures.
  5. Re-establish trust before returning the system to service.
