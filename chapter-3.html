Introduction to the Sysinternals Suite

The Sysinternals Suite is a collection of Windows diagnostic and security utilities. Its value comes from combining specialized views rather than treating any single tool as an oracle.

3.1 Getting Started

Download the Suite from Microsoft's official Sysinternals distribution, extract it to an analyst-controlled directory, and keep a known-good copy. In an enterprise, record tool versions as part of the investigation.

3.2 Choosing the Right Tool

Process Explorer

Process trees, executable metadata, handles, signatures, and process relationships.

Process Monitor

Detailed file-system, registry, process, and network-related event tracing.

Autoruns

Broad visibility into persistence and automatic execution locations.

TCPView

Real-time TCP/UDP endpoint and connection visibility.

3.3 Trust and Verification

Before relying on a tool during an investigation, verify its source and integrity. Keep copies of the exact versions used so another analyst can reproduce the workflow.

3.4 Evidence Discipline

Capture screenshots or exports only when useful, preserve timestamps, record filters, and document what was observed. Avoid changing a live system unnecessarily during collection.

Important: Sysinternals tools operate within the Windows security model. A sophisticated compromise may manipulate or hide information. Always consider independent evidence sources.
