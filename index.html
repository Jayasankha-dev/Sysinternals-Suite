About this handbook

This interactive handbook is designed as a structured learning path for cybersecurity analysts, threat hunters, incident responders, digital forensics practitioners, Windows administrators, and security students.

The handbook begins with Windows threat-hunting fundamentals and progressively moves into native Windows tools, Sysinternals utilities, advanced process monitoring, persistence analysis, network forensics, memory analysis, kernel security, firmware security, Android forensics, reverse engineering, malware-analysis methodology, threat intelligence, YARA, incident response, enterprise EDR/SIEM operations, hardening, and analyst playbooks.

Each chapter is maintained as an independent HTML page, making the handbook easy to expand and publish through GitHub Pages.
